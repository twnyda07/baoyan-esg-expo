# 心的永續力｜2026 亞太永續博覽會・寶嚴禪寺展區看板網頁版

The Sustaining Power of the Mind — Asia-Pacific Sustainability Expo 2026
Yuandao Culture and Education Foundation · Bao Yan Chan Monastery

展場看板中英文案的網頁版。**與會大眾**可自行閱讀，**解說員**可開啟「解說員模式」邊走邊講。

## 內容來源

| 檔案 | 用途 |
|---|---|
| `看板文案_中英定稿_2.doc` | 中英文案定稿（校訂後版本） |
| `永續展看板文案_中英定稿_印刷版 v2.docx` | 印刷版：補上台東詩、百萬華嚴／紀錄片、國際學習資源中心等段落，以及全部 89 張圖 |

網頁文字**逐字取自定稿，未改寫**；校訂說明（原稿的修訂註記）不收入公開頁面。
「解說要點」為依看板文字整理的導覽提示，未加入看板以外的事實。

## 功能

- **中文／中英／English** 三種語言模式，選擇會記住
- **解說員模式**（🎙）：每塊看板附「開場一句／講解重點／互動提問」，中英雙語
- **字級調整**（A－ / A＋），最大 1.5 倍，長者友善
- **搜尋**：輸入關鍵字即篩出相關看板
- **看板摺疊**：一塊看板 = 現場一塊實體看板，可對照現場位置查找
- **圖片燈箱**：點圖看大圖
- **QR 直接可點**：面相觀照、善知識抽籤在網頁上是可點的連結
- **分院附電話與 Google 地圖連結**
- **可列印**：列印時自動全部展開、含解說要點

## 檔案結構

```
index.html      版面、樣式、互動（單檔，無外部相依）
data.js         全部看板文字內容（中英）＋解說要點
images/         89 張圖，長邊 1600px（燈箱用）
thumbs/         同一批圖，長邊 760px（列表用，lazy load）
```

修改文案只需要改 `data.js`。

## 本機預覽

```bash
cd ~/寶嚴永續展看板網頁 && python3 -m http.server 8123
```

然後開 http://localhost:8123
