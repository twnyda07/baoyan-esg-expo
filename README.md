The Sustaining Power of the Mind — Asia-Pacific Sustainability Expo 2026
Yuandao Culture and Education Foundation · Bao Yan Chan Monastery

展場看板中英文案的網頁版。**與會大眾**可自行閱讀，**解說員**可開啟「解說員模式」邊走邊講。

## 內容來源

**《永續展看板文案_中英定稿 0806》**（`~/Downloads/永續展看板文案_中英定稿 0806.pdf`，2026-08-06 版）。
文字與 88 張圖片全部取自此檔，逐字未改寫；校訂註記不收入公開頁面。
「解說要點」為依看板文字整理的導覽提示，未加入看板以外的事實。

> 前一版（印刷版 v2）已淘汰。0806 版的差異見下方「版本差異」。

## 功能

- **中文／中英／English** 三種語言模式
- **☀ 一般／🌿 護眼／🌙 夜間** 三種閱讀模式
  護眼為柔和綠底（`#DFE9DC`）配深墨綠字，長時間閱讀不刺眼；夜間為深色底，暗處看不傷眼
- **字級調整**（A－ / A＋）0.85×–1.6×，長者友善；行高 2.05、字距加寬
- **解說員模式**（🎙）：每塊看板附「開場一句／講解重點／互動提問」，中英雙語
- **搜尋**：輸入關鍵字即篩出相關看板
- **看板摺疊**：一塊看板 = 現場一塊實體看板，可對照現場位置查找
- **圖片燈箱**：點圖看大圖
- **QR 直接可點**：面相觀照在網頁上是可點的連結
- **分院附電話與 Google 地圖連結**
- **可列印**：列印時自動全部展開、含解說要點

所有偏好（語言／閱讀模式／字級／解說員）都會記住。

## 檔案結構

```
index.html      版面、樣式、互動（單檔，無外部相依）
data.js         全部看板文字內容（中英）＋解說要點
images/         88 張圖，長邊 1600px（燈箱用）
thumbs/         同一批圖，長邊 760px（列表用，lazy load）
```

修改文案只需要改 `data.js`。

## 換新版原檔時的做法

```bash
# 1) 取文字
python3 -c "import fitz;d=fitz.open('新檔.pdf');print(''.join(p.get_text() for p in d))"
# 2) 取圖（依版面視覺順序、過濾裝飾線與全黑遮罩），再用 sips 轉 1600px / 760px
```
完整腳本流程見 git 歷史；QR 內容可用 `cv2.QRCodeDetector` 對 1000dpi 局部渲染解碼。
